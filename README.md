# Pokedex Frontend

Este es el frontend de la aplicación web **Pokedex**, diseñado con [React](https://react.dev/) y usando [Vite](https://vitejs.dev/) para obtener tiempos de carga ultrarrápidos.

## 📋 Prerrequisitos

Para arrancar el proyecto de manera local, necesitas tener instalado:

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/es/) (Se recomienda versión 18 o superior)
- Tener en ejecución el backend de Pokedex (API de NestJS).

## 🚀 Instalación y Ejecución Local

Sigue estos pasos para arrancar el entorno de interfaz visual.

### 1. Clonar el repositorio

Abre tu terminal y clona este repositorio:

```bash
git clone https://github.com/jehison-Gomez/Frontend-Pokedex
cd Frontend-Pokedex
```

### 2. Instalar Dependencias

Instala los módulos de Node requeridos:

```bash
npm install
```

### 3. Ejecutar el Servidor de Desarrollo

Inicia la aplicación en modo desarrollo:

```bash
npm run dev
```

> Por defecto, Vite abrirá o te proporcionará una URL local en la terminal (usualmente `http://localhost:5173`). Haz clic en ella o cópiala en tu explorador de internet para usar la aplicación.
